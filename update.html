Add a new host or update an existing one. Saving commits to the repo and the dashboard refreshes in about a minute.

1. GitHub token

Needed to save changes. It stays in this browser and is only sent to api.github.com.

How do I get a token?
  1. Open github.com/settings/personal-access-tokens/new
  2. Repository access: Only select repositories → AssetManagementTesting
  3. Permissions → Repository permissions → Contents: Read and write
  4. Generate the token and paste it above.
